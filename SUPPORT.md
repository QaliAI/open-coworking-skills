# Support

## Where to get help

- **Docs first**: [operator quickstart](docs/getting-started/operator-quickstart.md),
  [technical quickstart](docs/getting-started/technical-quickstart.md),
  and the [guides](docs/guides/).
- **Questions / how-do-I**: open a GitHub Discussion (or an issue with the
  question label while Discussions are not enabled).
- **Bugs**: use the bug-report issue template. Include the command, the
  output, and a synthetic or redacted sample that reproduces it — never a
  real export.
- **Security problems**: see [SECURITY.md](SECURITY.md) — private
  reporting only.
- **Integration requests**: use the integration-request template; read
  [adapters/README.md](adapters/README.md) for what support levels mean.

## What support covers

This is an open-source project maintained on volunteer time. Best-effort
responses, no SLAs. Commercial support, consulting, or vendor
partnerships are out of scope for the issue tracker.

## Before reporting analysis "errors"

Coworking metric definitions vary. If a number looks wrong, first check
the formula the output printed (every metric shows its numerator,
denominator, and exclusions) against the definition you expected — the
difference is usually definitional, and configurable.
