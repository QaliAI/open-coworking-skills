# Messaging

Use the operator's question, then the constraint.

| They say | We answer |
|---|---|
| Where are we losing money? | Revenue-recovery playbook. Leakage classes stay separate. |
| Why aren't leads converting? | Sales-conversion playbook. Speed, pipeline hygiene, and tour follow-up are different failures. |
| What goes vacant in 90 days? | Contracted forecast from end dates and notices. Unsigned pipeline is a scenario, labeled as one. |
| Who should we talk to before they leave? | Evidence list, not an opaque score. |
| Run a health check. | One command, a draft, a human attestation before anything is called reviewed. |

## Words we use

occupancy (and which kind), contracted, list price, notice, end date,
booked hour, sellable workstation, partner-billed, draft, attestation.

## Words we skip

thrilled, game changer, revolutionize, seamless, unlock, supercharge,
industry-leading, the AI-powered future of work.

## Proof we can show

The Northstar Coworking Demo is synthetic. On 2026-07-01 its three
occupancy figures are office 0.7143 (5/7), workstation 0.5758 (38/66),
and financial 0.6370 (11785/18500). Logo churn in that health-check window
is 0.0588 (1 of 17). Say "synthetic demo" in the same sentence.

## Install line

```bash
npx skills add QaliAI/open-coworking-skills --list
```

Node.js 22.20 or later. Set `DISABLE_TELEMETRY=1` if you do not want the
skills CLI's anonymous usage ping. That ping is the installer's, not ours.
The public GitHub form works after the repository is public. A local
checkout was tested on 2026-10-19.
