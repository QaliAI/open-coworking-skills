# LinkedIn 2 — why I built this

DRAFT.

The first time I asked an assistant "how full are we?", it answered with one percentage and a confident paragraph. The building had three different answers, and the bank cared about the third one.

I got tired of re-explaining that a 4-person office can be one unit and four workstations, that a comped office is occupied and earns zero, and that an out-of-service office should not sit in the sellable pool pretending to be demand.

So the explanations went into a skill the assistant loads, and the arithmetic went into a tested Python command. The skill is not allowed to invent the rent. If the cost file does not contain payroll, payroll is unknown, not zero.

That is the whole project. Teach the agent the coworking objects. Make the metric show its numerator. Leave the send button with a human.
