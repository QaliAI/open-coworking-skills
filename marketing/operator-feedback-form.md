# Operator feedback form

One form per job. Store the answers in a GitHub issue. Do not attach raw exports.

1. Location count (1, or more). Do not name members.
2. Workspace system, if you want to say (OfficeRnD, Nexudus, Optix, Archie, Cobot, other).
3. CRM, if any.
4. Question you asked, in your words.
5. Files you provided (entity names only: memberships, invoices, deals).
6. Was the result useful? (yes / partly / no)
7. Which number was wrong, and what is the right reading?
8. What was confusing in the terminology?
9. What export was painful to produce?
10. What workflow did you expect that was missing?
11. Which assumption was wrong for your business?
12. Which integration would have removed the export step?
13. Did you do anything different the following week? What?
14. May we quote this anonymously? (yes / no). Default is no.

A beta skill is promoted only when answers like 7 and 13 exist from an operator who is not the maintainer.
