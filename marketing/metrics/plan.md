# Measurement

Do not add telemetry to `opencoworking`. GitHub and the directories are enough.

Weekly, by hand, for 30 days:

| Signal | Where | Note |
|---|---|---|
| Stars, forks, clones | GitHub insights | Clones are traffic, not installs |
| Visitors and referrers | GitHub insights | |
| Issues and discussions | The repo | Separate bugs from operator feedback |
| Contributors | GitHub | A mapping correction counts |
| skills.sh or other directory installs | That directory, if it shows a number | Do not estimate |
| Operator beta replies | Your inbox and issues | Use the feedback form |
| Vendor replies | Your inbox | A correction is a success even if they decline a sandbox |
| Accepted articles | The publication | |
| YouTube views and average view duration | YouTube | Only after a video exists |
| LinkedIn comments that name a real objection | LinkedIn | Saves are vanity unless someone tries a skill |

Ignore a consulting lead that arrived because the README sounded like an agency. The README is an operator resource first. Record the lead anyway so you can see whether the wording drifted.

The 30-day LinkedIn follow-up stays a draft until these cells are filled from the tools above.
