# Launch kit

Drafts for a human to send. Nothing in this folder has been posted.
The Python package has no telemetry. Do not add any to measure this launch.

The public repository, once published, is
<https://github.com/QaliAI/open-coworking-skills>.

## What to say

Generic AI knows business. OpenCoworking Skills teaches it coworking.

Bring your own AI. Bring your own systems. Keep control of your data.

This is open-source operating knowledge for coworking agents. It is not a
prompt pack and not a workspace-management product. HubSpot and OfficeRnD
connectors in the repo are read-only prototypes tested on mocks. They are
not live integrations and not endorsements.

## What is in the box

24 stable skills, 13 beta skills, 22 planned skills, 8 playbooks, a
23-command CLI, and 233 tests. An earlier LLM judge scored 476 of 476
routing cases. The file now holds 518 cases. The 42 newer ones have not
been judged. Say that when you mention the suite.
