# OpenCode

**Support: native — OpenCode appears on the official Agent Skills client
showcase (verified 2026-07-17); its own docs define the mechanics and win
over this page:** https://opencode.ai/docs/skills/

## Install

1. **Work inside a clone** of this repository, or copy skill folders
   from `.agents/skills/` into the skills location OpenCode's current
   documentation specifies (project or global).
2. Where `gh skill install` supports an opencode target in your gh
   version: `gh skill install QaliAI/open-coworking-skills --all --allow-hidden-dirs
   --agent <target>`.

## Using the skills

Skills trigger by description relevance; Mode 2 export analysis needs
`python -m pip install -e .` from the repo clone.

If OpenCode's current documentation differs, follow it and open an issue
here so this page gets corrected.
