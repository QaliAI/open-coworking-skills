# Kiro

**Support: native — Kiro appears on the official Agent Skills client
showcase (verified 2026-07-17); its own docs define the mechanics and win
over this page:** https://kiro.dev/docs/skills/

## Install

Copy the skill folders you want from this repository's
`.agents/skills/` into the skills location Kiro's current documentation
specifies (project or user scope), or work inside a clone of this
repository if Kiro discovers project-level `.agents/skills/`.

## Using the skills

Skills trigger by description relevance during agent sessions. Mode 2
export analysis needs the Python package
(`python -m pip install -e .` from the repo clone).

If Kiro's current documentation differs, follow it and open an issue
here so this page gets corrected.
