# Integrations

Integration documentation lives in two places:

- **[adapters/](../../adapters/README.md)** — per-system field-mapping
  guides (generic CSV implemented; HubSpot, OfficeRnD, Nexudus, Optix,
  Archie mapping-documented) and the adapter contract for future
  connectors.
- **[docs/research/coworking-systems.md](../research/coworking-systems.md)**
  — the honest support-label ladder, what each label requires, and the
  full list of researched systems with their current status.

Nothing here claims connector support that hasn't been tested; see the
label definitions before reading any compatibility table. To add a
system, use the `coworking-system-adapter-builder` skill and the
integration-request issue template.
