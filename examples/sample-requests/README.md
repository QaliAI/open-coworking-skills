# Sample requests

Realistic operator requests to try against the Northstar Coworking Demo
data, with the skill each should trigger and the command it runs. The
matching machine outputs live in [../sample-outputs/](../sample-outputs/)
— generated by actually running the commands, never hand-written.

## "How full are we, really? The place feels busy but revenue is meh."

Triggers `coworking-occupancy-revenue-dashboard`. Mode 2:

```bash
python -m opencoworking.cli occupancy --inventory examples/synthetic-space/data/inventory.csv --memberships examples/synthetic-space/data/memberships.csv --as-of 2026-07-01
```

Output: [occupancy-dashboard.md](../sample-outputs/occupancy-dashboard.md).
The interesting part is the spread — 71.4% office count vs 63.7%
financial — and the flags naming OF-105's discount, DD-08's comp, and
OF-104 sitting out of service.

## "Where are we leaking money?"

Triggers `coworking-revenue-leakage-audit`:

```bash
python -m opencoworking.cli leakage --as-of 2026-07-01 --leads examples/synthetic-space/data/leads.csv --deals examples/synthetic-space/data/deals.csv --tours examples/synthetic-space/data/tours.csv --memberships examples/synthetic-space/data/memberships.csv --invoices examples/synthetic-space/data/invoices.csv --inventory examples/synthetic-space/data/inventory.csv
```

Output: [leakage-audit.md](../sample-outputs/leakage-audit.md). Note the
skill's job on top of the raw findings: annotating that M-016 is
partner-billed (possibly fine) while M-011 is expired-but-active
(definitely not fine), and refusing to sum billing gaps with pipeline
hopes.

## "Why aren't deals closing? Review the pipeline."

Triggers `coworking-pipeline-health`:

```bash
python -m opencoworking.cli pipeline --deals examples/synthetic-space/data/deals.csv --as-of 2026-07-01
```

Output: [pipeline-health.md](../sample-outputs/pipeline-health.md). D-2002
is the star: unassigned, stale 52 days, and duplicating D-2012/D-2001 for
the same buyer.

## Requests that should NOT trigger those skills

- "Write the follow-up for this morning's tour" → `coworking-tour-follow-up`
  (needs the five-question debrief; refuses generic check-ins)
- "A member gave notice — can we keep them as a mailbox client?" →
  `coworking-cancellation-to-virtual-office`
- "Is this occupancy claim in my investor deck true?" →
  `coworking-source-verifier`

Trigger phrasing per skill: each skill's `evals/cases.yaml`.
